# HEI Insights - MVP Central de Promoções

## Executar localmente
1. Instale Python 3.11 ou superior.
2. Na pasta do projeto, execute: `pip install -r requirements.txt`
3. Execute: `streamlit run app.py`

## Arquivos
- app.py: aplicação Streamlit
- pedidos_app.csv: recorte otimizado da tabela principal
- promocoes_app.csv: aba Export da base de promoções

## Escopo implementado
- Central de Promoções
- Ranking por operação
- Quantidade de promoções por operação
- Data do último pedido por operação
- Quantidade de pedidos por mês
- Detalhe da promoção
- Prévia de fechamento
- Página inicial de oportunidades
